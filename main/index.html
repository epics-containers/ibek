ibek#

ibek turns IOC instance YAML and reusable support definitions into an EPICS startup script and database substitutions. It also helps prepare generic IOC images and manage runtime patterns in services repositories.

Start with installation and render a small IOC configuration. For a specific task, use the CLI reference, Jinja context, or support-definition reference.

These pages document ibek itself. The epics-containers documentation covers the wider workflow: creating generic IOC images, configuring services, and deploying IOCs. How ibek fits connects the two.
